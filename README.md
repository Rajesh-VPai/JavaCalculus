# JavaCalculus
JavaCalculus is a Java-based symbolic algebra and calculus system designed to parse, transform, evaluate and validate mathematical expressions through a controlled symbolic-processing pipeline. 
## Release

### Version 1.0.0 | October 2026

Initial public release of JavaCalculus.

#### Highlights
- Symbolic algebra and calculus expression processing
- Expression simplification and transformation framework
- Function, constant, and parenthesis handling modules
- Integrated regression-test infrastructure
- Improved stability following Code Red hardening cycle
- Foundation established for future symbolic computation enhancements

#### Status
This release serves as the baseline public version. Future updates will focus on correctness, regression coverage, performance optimisation, and architecture harmonisation.
